VAMOS+ v1.1 アップロード手順

【重要】
ZIPファイルをそのままGitHubへ上げるのではなく、まずiPhoneの「ファイル」アプリでZIPをタップして解凍してください。

1. VAMOS_plus_v1.zipを「ファイル」に保存
2. ZIPをタップして解凍
3. GitHubの「ファイルを選択してください」を押す
4. 解凍したVAMOS_plus_v1フォルダを開く
5. index.html / manifest.webmanifest / sw.js / iconsフォルダ内の画像をアップロード
   ※iPhoneのGitHub画面でフォルダをまとめて選べない場合、PCからのアップロードが簡単です
6. 「変更をコミット」
7. リポジトリの「設定」→「Pages」
8. Branchを main、フォルダを /(root) にして保存
9. 数分後に表示されるURLをSafariで開く
10. Safariの共有ボタン→「ホーム画面に追加」

データについて
・体重、食事、写真、運動、健康記録はSafariの端末内にだけ保存されます
・GitHubへ個人データは送信されません
・Safariの履歴・Webサイトデータを削除すると記録も消える可能性があります
・設定画面から定期的にバックアップしてください
